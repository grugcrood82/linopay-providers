# Code of Conduct

## Our pledge

We want this project to be welcoming to anyone who integrates with
LinoPay, regardless of their background, language, or the size of the
business they're building on top of it. Disrespect, harassment, or
exclusionary behaviour have no place here.

## Expected behaviour

- Be welcoming. Assume good faith. Read carefully before reacting.
- Argue the idea, not the person. Disagreement on design is healthy;
  personal attacks are not.
- Ask before you assume. Especially across language boundaries — a
  pattern that's idiomatic in one SDK may feel strange in another.
- If you spot a mistake, fix it or report it kindly. Don't both.

## Unacceptable behaviour

- Harassment of any kind — verbal, written, or implied.
- Public or private aggression towards a contributor, maintainer, or
  user of the software.
- Publishing another's private information without consent.
- Any conduct that a reasonable person would find intimidating,
  hostile, or unwelcoming.

## Reporting

Instances of unacceptable behaviour can be reported to the project
maintainers via GitHub issues (private security advisory if it's
sensitive) or via the contact details in `lime-payments`'s public
README. All reports are taken seriously and reviewed promptly.
